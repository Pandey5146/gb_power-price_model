# GB Power Price Forecast Model

## What I built
- NESO wind forecast pipeline
- NESO demand forecast pipeline
- Historical demand and wind dataset
- Residual demand model
- Linear regression price model
- Forward price curve
- Trading signals

## Project workflow
1. Collect data from APIs
2. Clean and store data
3. Build residual demand features
4. Merge with historical price data
5. Train price model
6. Generate forecasts
7. Create trading signals
